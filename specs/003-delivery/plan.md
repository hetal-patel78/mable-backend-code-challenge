## Summary

This spec owns [NFR-04](../../docs/solution-design/03-non-functional-requirements.md#nfr-04) Language version and portability, and delivers what a reviewer needs around the finished program built by `001-domain` and `002-file-runner`: the README ([DEC-37](../../docs/design-analysis/design-decisions.md#dec-37)) with the coverage figure ([DEC-36](../../docs/design-analysis/design-decisions.md#dec-36)), a GitHub Actions workflow running RSpec and RuboCop on every push, a Dockerfile as the fallback way to run, the [`Gemfile.lock`](../../Gemfile.lock) platforms, and the checks that prove them: CI, a Docker run, a Windows run and a Linux or macOS run from a clean checkout, the README check and the submission check ([DEC-38](../../docs/design-analysis/design-decisions.md#dec-38)).

It changes no behaviour of the program and adds no class, no message, no RSpec spec and no test-data file ([FR-030](spec.md#fr-030), [brief rule 4](../../docs/spec-kit/spec-kit-brief.md#4-how-the-tests-are-split)). Its "tests" are the checks in [quickstart.md](quickstart.md): each is written before the file it checks, seen to fail, and passes once the file is in place.

## Technical Context

**Language/Version**: Ruby, the latest 3.4.x release, exactly the version in [`.ruby-version`](../../.ruby-version) (set by `001-domain`, [FR-036](../001-domain/spec.md#fr-036) there; [DEC-01](../../docs/design-analysis/design-decisions.md#dec-01)). This spec repeats that version in one place only, the Dockerfile's base image ([FR-015](spec.md#fr-015)).

**Primary Dependencies**: none added. Runtime gems `csv`, `bigdecimal` and `logger`; development gems `rspec`, `simplecov`, `rubocop` and `rubocop-rspec`, all set by `001-domain` ([FR-037](../001-domain/spec.md#fr-037) there). Bundler, with [`Gemfile.lock`](../../Gemfile.lock) committed. Outside the program: GitHub Actions with the actions `actions/checkout` and `ruby/setup-ruby`, and the official Ruby Docker image ([DEC-36](../../docs/design-analysis/design-decisions.md#dec-36)). No other gem, framework, tool or library.

**Storage**: N/A. Files only: the README, the workflow file, the Dockerfile and the platform list in [`Gemfile.lock`](../../Gemfile.lock).

**Testing**: no new RSpec spec ([FR-030](spec.md#fr-030)). The existing suite (RSpec in random order, with SimpleCov) and RuboCop with `rubocop-rspec` run in CI, in Docker and on each clean checkout. This spec's own checks are the commands [C-01](quickstart.md#c-01) to [C-43](quickstart.md#c-43) in [quickstart.md](quickstart.md), run by hand or by the implementing agent, with each result recorded in the run report ([`docs/spec-kit/implementation-run-report.md`](../../docs/spec-kit/implementation-run-report.md)).

**Target Platform**: Linux and macOS ([`bin/run`](../../bin/run)), Windows (`ruby bin/run`), Docker (Linux containers, on an x86-64 or ARM64 host), and the latest Ubuntu runner on GitHub Actions ([NFR-04](../../docs/solution-design/03-non-functional-requirements.md#nfr-04); [page 10 picks 20](../../docs/solution-design/10-traceability-glossary-assumptions.md#pick-20) and [50](../../docs/solution-design/10-traceability-glossary-assumptions.md#pick-50)).

**Project Type**: command-line program (single project); this spec adds delivery files around it.

**Performance Goals**: none. [NFR-02](../../docs/solution-design/03-non-functional-requirements.md#nfr-02) and [NFR-03](../../docs/solution-design/03-non-functional-requirements.md#nfr-03) are owned elsewhere and checked by design review.

**Constraints**: one Ruby version, written in [`.ruby-version`](../../.ruby-version) and the Dockerfile only; [`Gemfile.lock`](../../Gemfile.lock) installs unchanged, frozen, on Windows, the CI runner and the Docker image; no coverage minimum, no CI matrix, no Ruby version in the workflow; nothing added to the Dockerfile beyond [DEC-36](../../docs/design-analysis/design-decisions.md#dec-36); no `.dockerignore`; every text file stored with LF; nothing out of scope on [page 4](../../docs/solution-design/04-scope.md).

**Scale/Scope**: 4 files created or changed ([`README.md`](../../README.md), [`.github/workflows/ci.yml`](../../.github/workflows/ci.yml), [`Dockerfile`](../../Dockerfile), [`Gemfile.lock`](../../Gemfile.lock)), and [`bin/run`](../../bin/run) may also change (its Git mode, its first line and, only if RuboCop reports it, the line-2 `# frozen_string_literal: true` comment; [FR-018](spec.md#fr-018), [spec item 16](spec.md#item-16)), 43 checks, 6 user stories.
